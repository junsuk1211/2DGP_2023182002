# 소닉 애니메이션 뷰어 PRD

## 1. 개발 목표

`sonic-sprite.png`에 포함된 모든 동작 애니메이션을 제자리에서 재생하는 뷰어를 작성한다.

## 2. 개발 환경과 파일

| 항목        | 요구사항                                |
| ----------- | --------------------------------------- |
| 라이브러리  | pico2d                                  |
| 소스코드    | `sonic_animation_viewer.py` 단일 파일 |
| 대상 이미지 | `Labs/LEC09/sonic-sprite.png`         |

## 3. 화면 표시

- 화면 크기는 가로 **1200픽셀 × 세로 800픽셀**로 설정한다.
- 캐릭터는 제자리에서 애니메이션을 재생하며 화면 내 위치를 이동하지 않는다.
- 캐릭터는 원본 이미지의 **5배**로 확대한다. 기존 10배 확대 크기의 **50%**로 표시한다.

## 4. 애니메이션 재생 규칙

스프라이트 시트에 들어 있는 모든 동작 애니메이션을 다음 순서로 재생한다.

1. 현재 동작 애니메이션을 **5회** 재생한다.
2. 해당 동작의 재생이 끝나면 **1초** 쉰다.
3. 다음 동작으로 넘어가 같은 규칙으로 재생한다.
4. 모든 동작의 재생이 끝나면 첫 동작부터 다시 **무한 반복**한다.

## 5. 개발 진행 방식

- 한꺼번에 완성하지 않고 단계별로 개발한다.
- 단계별 작업을 커밋하며, 개발 커밋을 **최소 20개 이상** 남긴다.
- 커밋 메시지는 **반드시 한글로 작성한다**.
