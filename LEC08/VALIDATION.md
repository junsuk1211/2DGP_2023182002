# 검증 기록

2026-10-01, Windows / Python 3.13 / Pico2D 환경에서 검증했습니다.

- `python -m unittest discover -s LEC08 -v`: 4개 테스트 통과.
- `python -m compileall -q LEC08`: 구문 오류 없음.
- 총 29개 프레임의 픽셀을 원본 영역과 비교: 배경 투명 처리 외 차이 없음.
- 프레임 영역이 잘리지 않고 투명 배경 `(0,128,0)` 제거됨을 확인.
- 실제 Pico2D 창을 18.1초간 실행: run → walk → jump → Y combo → run 순환 확인.
- 네 동작의 재생 구간과 1초 정지 구간 총 8개 상태를 SDL 렌더러에서 캡처.
- ESC 키 이벤트로 루프 종료와 캔버스 정리를 확인.
- 전체 프레임 모음과 실행 화면을 시각적으로 확인.

`preview.png`는 실제 창에서 캡처한 네 동작을 한 이미지에 배치한 미리보기입니다.

## 실행 중 확인한 수정

SDL 창 제목과 확대 품질 설정을 사용할 수 있도록 Pico2D 내부 모듈을 직접 가져옵니다.
캔버스를 생성한 뒤의 `window`와 `renderer`는 해당 모듈에서 접근해야 합니다.
